# TAP 工作空间操作指南

直接用浏览器打开 dist/Workpal.html。首次打开会进入用于 TAP 项目开发的预置空间。点击侧栏顶部的工作空间名，可以切换空间，或选择 Create workspace 创建独立空间。新空间从创建第一个项目开始。

| 入口 | 操作 |
| --- | --- |
| Projects → TAP | 点 New issue，填写标题，选团队和 Agent。保存在 Backlog 会暂存任务。切换到 To do 时可以选择是否启动。 |
| Issues | 用负责人和状态筛选，切换列表或看板。打开 issue 可发评论、添加子任务、查看运行记录。评论中输入 @Quality partner 会让该 Agent 处理这次请求，并保留原负责人。 |
| Workflow runs | 打开运行，填交付备注后提交评审。选择批准或要求修改。退回后可另开一次运行，两次记录均保留在 issue 中。 |
| Skill Hub | 按名字或仓库搜索，查看来源及安装命令，把 Skill 绑定到指定 Agent。在 Agent 资料页核对绑定结果。 |
| Ask Workpal | 输入 “Create issue titled Check citation coverage”，在对话中创建任务。输入 “Chart quality team issues by project” 生成可固定的团队面板。 |
| Reports | 在具体运行中生成执行报告，或在统计页面生成团队摘要。打开保存的快照可导出 Markdown。 |

工作区数据保存在当前浏览器。分享 HTML 文件可查看内置目录。个人新增的 issue、绑定和报告保存在各自浏览器。
