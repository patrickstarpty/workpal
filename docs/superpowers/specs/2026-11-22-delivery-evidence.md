# Reviewable delivery evidence
User approved implementation on 2026-11-22. Each deliverable has immutable content, a kind, a version, ticket and producing Activity, and an optional real Run (human work must not invent a Run). Requirements/design contain the full document; code includes diff and review findings/fixes/recheck; tests include method/results/failures/uncovered scope; handoffs name exact input revisions. Authenticated reviewers record acceptance and remaining issues against an immutable revision. Existing records remain intact and unsupported claims show evidence pending. No invented execution or approvals.
Approach: extend SQLite workspace records and existing issue UI. Attachment counts and richer seed summaries cannot establish evidence. Structured fields enforce completeness, not truth; review remains a human decision.
