## 已确认的关键差异

- **上传不是图片专用接口。** `server/go/internal/handler/file.go:388` 的 UploadFile 使用 100 MiB 上传错误边界，检测内容并处理扩展名；支持个人/工作区归属、issue/comment/chat/task 关联及相应私有资源/token 校验。Go `file_test.go`、`chat_attachment_reply_test.go` 有对应行为测试。Python `files/routes.py` 当前为 5 MiB 图片兼容实现，关联字段返回 501。头像成功不构成 Go 附件等价。
- **项目列表的权限属于查询语义。** `server/go/internal/handler/project.go:197` 起解析查询，归档默认不返回；先按 requestHiddenProjects 和条件筛选，再排序分页，返回完整分页信息。Python `workspace_content/routes.py` 的 collection_list 主要按 status/project_id/q 筛选通用记录，execute 主要核对 workspace membership。不能据此宣称私有项目、排序/分页和计数等价。
- **配置基准不等同 Python 名称。** `server/go/cmd/server/main.go:298` 起使用 JWT_SECRET/APP_ENV 和 Go 校验；Makefile 的 selfhost 初始化生成 `.env` 并保留已有值。当前 Python AUTH_SECRET/WORKPAL_ENV 与运行方式需要明确兼容映射及测试，不能只复制“.env 文件”就声称行为相同。
- **路由之外仍有协议。** router.go 的全局 CORS、trusted proxy、WS、嵌套 With/Use、comment keep-replies、daemon/task 身份等均需要列入行为账本；main/scheduler 注册和事件生产者不能靠前端调用清单覆盖。
- **存储翻译仍需证据。** Go queries 包含 FOR UPDATE/SKIP LOCKED 等语义；schema-map 复制 DDL 不代表 SQLite 已等价实现。并发、搜索和私有资源过滤必须分别验证。
