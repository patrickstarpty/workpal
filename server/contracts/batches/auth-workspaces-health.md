# Auth, workspace and health evidence

Status: Go source evidence only. Python implementation and executable contract verification are pending. routes.json remains candidate extraction; references here are method/path joins, not a claim it is verified.

## Security and sessions

Public routes: health aliases, config, send-code, verify-code, Google and logout. Auth rate limit defaults to 5/minute; verify defaults 20/minute. Per-email send-code limit is 60 seconds. Go codes expire after ten minutes; query excludes used, expired and attempts >=5. Wrong codes increment attempts. Email is trimmed and lowercased; code is trimmed. Missing values return 400. Wrong/expired code returns 400 {"error":"invalid or expired code"}. Go JSON decoder accepts unknown keys; null pointer fields and omitted pointer fields both mean no update. Do not expose FastAPI's default 422 body.

Authorization bearer takes precedence over cookies. Cookie writes require X-CSRF-Token; safe methods GET/HEAD/OPTIONS bypass CSRF. Middleware strips client actor-source, agent and task identity headers. mul_ PAT, mat_ task and mcn_ cloud credentials have separate validators; never treat them as session JWTs. Refresh rejects authenticated non-session credentials with 400 {"error":"only interactive sessions can be refreshed"}; expired credentials fail authentication first. External cloud verification is unsupported locally and must fail explicitly.

JWT login claims: HS256 sub,email,name,sid,exp,iat. Default TTL 30 days; AUTH_TOKEN_TTL accepts Go duration or integer seconds, invalid values default and values below one minute clamp. Renewal only for live tokens with remaining lifetime <=TTL/2; retain sid, update expiration. Cookie renewal occurs only on authenticated safe requests. Explicit refresh returns expires_at,renewed,check_again_in_seconds; token appears only on renewed bearer response. Cadence TTL/10 clamped to 5 seconds..7 days and capped at half renewal threshold. No session database row or refresh token. Logout clears cookies, does not revoke copied JWTs.

Cookies: workpal_auth HttpOnly; workpal_csrf and workpal_csrf_session readable. All Path=/, SameSite=Strict, MaxAge=TTL seconds, Expires=now+TTL. Secure derives from https FRONTEND_ORIGIN. COOKIE_DOMAIN is trimmed; IP literals ignored. Logout expires all three with MaxAge=-1 and Unix epoch. CSRF format hex(16 random bytes).hex(HMAC-SHA256). Legacy signature uses JWT token as key and nonce as message; session binding uses JWT secret as key and sid + NUL + nonce as message. Accept either binding from one X-CSRF-Token header; prefer session cookie in frontend. CSRF failure is 403; missing authorization 401. Middleware uses http.Error with JSON-looking text and newline; handler errors use JSON error objects. Preserve status/body rather than assuming identical content types.

Approved adaptation: WORKPAL_DEV_AUTH=true only development on loopback; production startup rejects flag. Normalize email then permit only dev@workpal.local and fixed code 888888. Persist/reuse one user atomically, never bypass memberships. send-code sends no mail. Google and actual email delivery must return explicit unsupported errors (proposed 501 {"error":"Google authentication is not supported"} / 501 {"error":"Email delivery is not supported"}); these are migration decisions, not Go responses. Advertise an explicit development-auth capability; frontend prefill only on true, editable and manually submitted. Go's WORKPAL_DEV_VERIFICATION_CODE behavior is broader and is not the approved Python adaptation.

## Workspace persistence and HTTP behavior

Create trims name, lowercases/trims slug; required nonempty; slug ^[a-z0-9]+(?:-[a-z0-9]+)*$ and reserved-slug check. Duplicate slug 409. Prefix trims/uppercases, 1..10 A-Z0-9; absent/blank derives first four slug alphanumerics uppercase. Create transaction includes workspace, owner member and seven issue statuses, rollback on any failure. Does not mark onboarded. 201 response. Creation disable/allowlist enforced server side with 403.

List only joins caller membership, pinned DESC NULLS LAST then workspace.created_at ASC. Empty list is []. Selection is frontend state, no select endpoint: restore remembered workspace only after this authorized list; match URL first segment against authorized slug; resolve actual id for API calls and platform providers. Never hardcode review slug. Zero workspaces shows creation, one selects it, multiple selects explicitly. Clear scoped queries and disconnect realtime on logout/expiry/switch. Refresh must resolve /api/me before showing authenticated content.

Workspace response nulls description/context/avatar; settings {} and repos [] fallback; unpinned pinned_at omitted (pin response explicitly null). Update name blank 400; null and absent scalar pointers do not clear, empty description/context do. Empty prefix leaves existing. Repos validates array of objects with valid http(s)/SSH git URL, trims and deduplicates by URL; settings JSON replacement includes legacy PR switch reconciliation. Admin or owner may update; owner only delete. Pin requires boolean (null/missing invalid 400), stores per-member timestamp.

Members response joins global user name,email,avatar_url. /members POST creates invitation, not direct membership! Role updates/admin removal require workspace owner/admin router middleware; only owners can manipulate ownership. Last owner cannot be demoted/removed/leave: 400 {"error":"workspace must have at least one owner"}. Cross-workspace member IDs 404. Removal and leave return 204. Removal runs revokeAndRemoveMember transaction, disconnects membership realtime, invalidates caches, releases capacity, emits revocation side effects and member removal. Preserve this beyond deleting a join row.

SQLite translation: UUID -> canonical text, timestamptz -> UTC serialized text with central precision, boolean -> INTEGER CHECK IN(0,1), JSONB -> JSON text with json_valid checks. user id PK; email UNIQUE NOT NULL; name NOT NULL; avatar nullable; created_at/updated_at NOT NULL. Include language/timezone/onboarded_at, questionnaire JSON default {}, profile_description default '', whats-new nullable, star prompt count default 0 and nullable timestamps. workspace id PK, slug UNIQUE NOT NULL, name NOT NULL, description/context/avatar nullable, settings default {}, repos default [], issue_prefix, issue_counter and attribution_fail_closed persisted. member id PK, workspace_id and user_id NOT NULL, UNIQUE(workspace_id,user_id), role CHECK owner/admin/member, created_at and nullable pinned_at; enforce parent relationships explicitly even where later Go migrations removed FKs. verification_code id PK,email/code/expires_at NOT NULL, used default false, attempts default 0, created_at; index email/used/expires_at. No implicit SQLite case-insensitive email assumption: normalize at boundary. No PostgreSQL casts, ANY arrays or data-modifying CTE copies. Translate deletion CTEs to ordered statements in one transaction, preserve media cleanup ledger and feedback/client_usage null detachment. BEGIN IMMEDIATE plus rechecking ownership inside transaction protects concurrent last-owner changes and workspace delete/session create; do not emulate FOR UPDATE with a no-op SELECT.

## Events and verification obligations

UpdateWorkspace emits workspace:updated payload {workspace: WorkspaceResponse}; name/settings changes also notify member daemons. UpdateMember emits member:updated {member: MemberWithUserResponse}. DeleteMember/Leave emit member:removed {member_id,workspace_id,user_id} after revocation; revocation emits agent:archived and daemon:register as described in source below. DeleteWorkspace emits workspace:deleted {workspace_id} and refreshes affected daemons after commit. CreateWorkspace sends daemon refresh after commit, no workspace:created. Pin emits none. Auth only emits signup telemetry on first account creation, no realtime business event. Read/config/health emits none.

Go publish delegates to Bus.Publish; frontend use-realtime-sync consumes workspace:updated into list cache, workspace:deleted switches away and member:removed removes access. Required Python events belong in same SQLite transaction outbox; Go's post-commit bus calls are not evidence of atomic delivery. Commit/rollback/Redis-outage/restart/stable-ID duplicate consumer tests are pending per producer. Do not mark compatibility passing from static inspection.

Required fixtures: anonymous me 401; cookie write missing CSRF 403; wrong code 400; correct normalized credentials; repeated login same user; disabled dev auth; production rejects flag; PAT/task refresh 400; forged actor headers discarded; expired JWT 401; safe renewal retains sid and old session CSRF; create collision 409; injected owner/status failure leaves no workspace; no/multiple memberships; removed remembered slug rejected; cross-workspace member 404; last owner guarded concurrently; pin per-member ordering; reopen preserves all rows; deletion cleans no-FK descendants and preserves deferred storage cleanup ledger. These are required tests, not executed results.
