# Authenticated workspace WebSocket contract

Status: source-bound specification; transport implementation and tests pending. Fixtures use illustrative IDs and timestamps, not captured production records. This batch changes no runtime. Approved scope: docs/superpowers/specs/2026-11-21-python-go-backend.md and docs/superpowers/plans/2026-11-21-python-go-backend.md, Task 7.

## Browser and handshake

apps/web/app/main.tsx constructs ws(s)://location.host/ws with cookieAuth. packages/core/realtime/provider.tsx starts only with user, workspace slug and URL; workspace switch/sign-out disconnects the previous socket. packages/core/api/ws-client.ts connect sets workspace_slug and optional client_platform/client_version/client_os using URLSearchParams. No token query parameter, cursor, Authorization header or CSRF query is sent. Browser attaches workpal_auth cookie. Token clients send auth as their first frame and wait for auth_ack; cookie clients consider open authenticated and receive no auth_ack.

server/go/cmd/server/router.go registers GET /ws outside API middleware, resolving slug with GetWorkspaceBySlug. server/go/internal/realtime/hub.go HandleWebSocket prefers workspace_id over workspace_slug; neither yields HTTP 400; failed slug resolution 404. Cookie invalid -> 401, disabled account -> 403, membership false -> 403, lookup error -> 503, before upgrade. Missing cookie takes first-frame auth path, NOT anonymous subscription. First frame deadline 10 seconds; JWT or resolved PAT is checked then membership. Failure writes bare {error:string} and closes, not a typed auth_error (the helper's logging name is misleading). Query tokens are not a credential. Python browser implementation must validate signed session and stored session revocation, not merely decode a user ID.

Go checkOrigin allows absent Origin, same Host, matching forwarded host only from trusted proxy, or configured allowlist. Python must explicitly implement trusted-proxy and allowlist policy; never trust arbitrary forwarded headers or wildcard origins. Browser GET upgrade has no x-csrf-token; Origin is its cross-site defense, unlike mutating HTTP CSRF dependency. Do not require a custom browser header it cannot send. Absent-Origin support is for authenticated native clients, never an authentication bypass.

## Frames and authorization

See realtime.json fixtures. Go inboundFrame={type,payload}; subPayload requires nonempty scope/id. Invalid JSON and unknown types are ignored; invalid subscription payload produces subscribe_error/unsubscribe_error with scope,id,error=invalid payload. ping -> pong. Explicit workspace/user subscriptions must match connection identity; task/chat use AuthorizeScope. Errors: forbidden, lookup_failed, unknown_scope. Successful subscribe/unsubscribe ack mirrors scope/id; repeated subscribe is idempotent. Unsubscribe delegates to Hub and acknowledges without authorizing a new audience. Go automatically joins workspace, user and internal workspace-member scopes on registration (membership.go); internal workspace-member scope is not a public subscribe option.

Python MUST fail closed when scope authorizer is missing, errors, or cannot prove same-workspace resource visibility. Go's nil authorizer path in handleSubscribe is permissive; do not copy it. First vertical slice may deny every task/chat subscription with subscribe_error until implemented. User scope cannot expose another workspace's private member events. Chat content belongs only to session creator; missing ChatSessionOwnerID drops, never workspace fallback. Member-private events need MemberPrivateUserID and workspace-bound recipient. Private project routing requires proven audience (server/go/cmd/server/private_project_realtime.go); unknown event types or unresolved private audience must not default to workspace. No general internal-envelope passthrough.

Go membership.go validates current membership at content-write boundary, and membership_removal.go/batch machinery disconnect affected sockets, including relay invalidations. Python must recheck authoritative membership and session validity before every outbound content batch, including queued messages; lookup failure closes without content. Logout/revoked session/expiry must terminate existing sockets and reject reconnect; provider cleanup alone is insufficient. Go handshake token validation is not evidence of ongoing expiry enforcement. Implement expiry deadline and revocation signal or bounded authoritative checks; specify and test the bound before claiming completion. Rejoined membership must survive stale removal signals; confirmed removal may send member:removed notice then close. Never drain queued private content after revocation.

## First actual event and transport seam

Go workspace.go UpdateWorkspace publishes workspace:updated with payload {workspace:workspaceToResponse(ws)}. WorkspaceResponse defines id,name,slug,description,context,settings,repos,issue_prefix,avatar_url,created_at,updated_at and optional pinned_at. Nullability and default settings={} / repos=[] come from serializer. packages/core/types/events.ts WorkspaceUpdatedPayload and use-realtime-sync.ts applyWorkspaceUpdatedToCache require the nested workspace object.

Internal Event fields in server/go/internal/events/bus.go map type->type, payload->payload, actorID->actor_id, actorType->actor_type. workspaceID selects audience; it is not copied into the outbound frame. server/go/cmd/server/listeners.go registerListeners/projectOutbound performs audience filtering and strips internal-only keys for other event families. eventID is Python outbox dedup metadata, not a browser cursor. Only validated workspace:updated with matching workspace.id/workspaceID and no private hints may use this first-event adapter. Append in the same SQL transaction as authorized update; rollback must leave neither record nor event. Preserve stable eventID through retry.

Current infrastructure/delivery.py XADDs one envelope JSON field into redis_key_prefix + events:stream, then SQL ack means Redis acceptance only. It is NOT Go realtime transport. Go redis_relay.go uses ws:scope:<scope>:<id>:stream with separate fields event_id,event_type,scope,scope_id,workspace_id,actor_id,created_at,node_id,payload_json. payload_json is the already projected browser frame; workspace_id in relay envelope can mean excluded workspace, not domain workspaceID. Sharded relay is another explicitly configured mode (sharded_stream_relay.go); no automatic compatibility assumption.

Required new seam: an internal-stream consumer decodes/validates envelope, allowlists event type, projects frame, resolves authorized audience, and hands (stable eventID, scope, scopeID, frame) to a Python hub/relay adapter. Persist consumer progress/dedup independently from SQL delivery ack. A crash after fanout before consumer ack may redeliver; consumers must be idempotent. Invalid/private unresolved envelopes fail closed with observable quarantine/error, never broad fanout. If bridging to Go legacy streams, write its exact fields and keys via an explicit adapter; do not point Go at events:stream. Adapter ownership, durable checkpoint schema, poison-event policy and selected relay mode remain implementation decisions requiring tests. No adapter currently exists by virtue of this contract.

## Reconnect and retention

WSClient reconnects with exponential capped delay and jitter, rereads token, and invokes reconnect callbacks for refetch. It sends no last event ID, cursor or resume request; there is no browser replay guarantee or event ack. Go relay stream cursors are server-side node consumption, not browser cursors. stream_retention.go defaults trim horizon 10 minutes, TTL 15 minutes, refresh 30 seconds, maintenance one minute; TTL opt-in disabled by default. Python internal stream currently has no trim/expiry. Do not apply Go defaults to it before checkpoint/consumer retention safety is designed. Reconnect must authenticate again, refetch authoritative HTTP state and avoid displaying revoked caches. Offline gaps are resolved by refetch, not invented browser replay.
