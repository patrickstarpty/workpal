# Core query transport coverage

All six target sources were read completely in bounded, untruncated output, including callback bodies. Companion JSON records current hashes, export anchors, concrete API methods and existing inventory IDs/methods/path expressions/routes. Supporting files are explicitly partial.

Agents queries: snapshot, working agents, 30-day activity, run counts, paged history, builder sessions and context receipt each have one concrete queryFn. History forwards signal, limit=200 and before=pageParam; next-page callback returns nextCursor or undefined and performs no transport. Working agents forwards type/relation/parent (relation takes precedence over parent in client). Builder list enabled for nonempty wsId, staleTime=0; client 404 returns empty and parsing falls back. Receipt enabled for both IDs. Remaining keys are pure arrays.

Activity hook registers agentListOptions and agentActivity30dOptions with enabled=!!wsId. Its memo/buildActivityMap/deriveAgentActivity/summarizeActivityWindow/startOfDay only group, zero-fill, sum, clamp and calculate local dates; interfaces/constants/__EMPTY_ACTIVITY have no transport. Presence prefetch registers four useQuery observers (agents, runtimes, snapshot, squads), all enabled=!!wsId; it does not call prefetchQuery. Reused retry audit closes agent-list polling and snapshot/working agents; status-helper limitations are historical and retry audit closes its specified followups. Active-web-auth supplies shared context and invalidation semantics, not backend evidence.

Connected-apps: eight factories mapped separately, including two listAppRequests callbacks. calls/apps/requests promise projections are local; request factories pass issueId or chatSessionId, omit before and discard next_before. Catalog omits view and has five-minute stale time. Other key exports only construct arrays. Notification preferences forwards optional workspaceSlug; truthy slug sets X-Workspace-Slug override while cache remains keyed by wsId.

Billing checkout posts serialized data; portal posts without body. Both parse returned JSON with fallback and return URLs; neither callback navigates. Checkout onSettled invalidates billing/topups locally on success or failure. Portal has no invalidation. useInvalidateBillingDataAfterCredit returns a local callback invalidating balance/transactions/batches/topups prefixes. Supporting billing factories define the possible refetch union recorded in JSON; price tiers and checkout-session keys do not match these prefixes. Standard Tanstack observer state controls actual refetches; no runtime observer enumeration or request count is asserted.

Client parse/fallback and promise projection introduce no additional endpoint. Standard React, Tanstack and Zod semantics end tracing; no node_modules audit. Shared auth transport is reused rather than re-audited. No unresolved bounded transport edge remains. Arbitrary runtime observers and backend implementation are outside this audit.

Validation: every edge resolves to an existing inventory ID and copied method/path/route; every recorded file and anchor exists. Only three owned artifacts written; no runtime or backend tests needed for this static evidence.
